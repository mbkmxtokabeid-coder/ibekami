fix: Implement comprehensive PWA install prompt prevention

PROBLEM:
- Android browsers show "Access other apps and services" popup
- Users panic and click "Block"
- Website becomes blank/inaccessible after "Block"
- High bounce rate and lost conversions

SOLUTION:
Implemented multi-layer defense system (4 layers + 6 JavaScript sub-layers):

1. HTTP Headers (.htaccess):
   - X-Robots-Tag: noindex, nofollow, noarchive, nosnippet
   - Permissions-Policy: display-capture=(), web-share=()
   - Manifest cache control (no-cache)

2. Manifest.json:
   - display: "browser" (NOT "standalone")
   - prefer_related_applications: false
   - Empty arrays for related_applications, shortcuts, etc.

3. Meta Tags:
   - mobile-web-app-capable: no
   - apple-mobile-web-app-capable: no
   - robots: noindex, nofollow

4. JavaScript Prevention (6 sub-layers):
   - Block beforeinstallprompt event
   - Block appinstalled event
   - Unregister all service workers
   - Block future service worker registration
   - Override display-mode detection
   - Clear PWA-related storage

5. Laravel Middleware (Backup):
   - PreventPWA middleware
   - Automatic fallback if .htaccess fails
   - Adds headers programmatically
